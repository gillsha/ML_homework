Матрица R[фильм][пользователь]: строки — фильмы, столбцы — пользователи. User-based сравнивает столбцы, item-based — строки.

Пропуск ≠ 0. Сравниваем только совместно оценённые объекты, центрируем оценки относительно среднего. Не менее 3 общих оценок; сходство уменьшаем множителем n/(n+10); до 30 положительных соседей.

Топ-10 для выбранного пользователя

Показанная оценка ограничена 1–5, а не является вероятностью. Ранжирование использует исходный конечный score до ограничения диапазона. Полный датасет используется для рекомендаций. Fallback — регуляризованное среднее с поправками пользователя и фильма; фильмы без оценок исключены.

Детерминированно скрываем около 20% оценок каждого пользователя, оставляя минимум одну в train. Это проверка восстановления оценок, не будущих просмотров и не релевантности топ-10. Cold start нового пользователя можно проверить в списке выбора.
